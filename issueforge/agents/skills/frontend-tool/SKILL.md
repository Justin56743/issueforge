# Frontend Design & Craftsmanship

Create distinctive, production-grade frontend interfaces with high design quality, crisp aesthetics, and exceptional attention to detail.

## Core Directives

1. **Avoid Generic AI Aesthetics**:
   - Reject cliched layouts, flat purple gradient cards on white backgrounds, and uninspired cookie-cutter designs.
   - Design with a strong, intentional aesthetic perspective (e.g. sleek dark-mode developer environments, industrial/utilitarian dashboards, or refined minimalism).

2. **Typography & Hierarchy**:
   - Establish crystal-clear hierarchy using font weight, scale, and subtle opacity levels (`text-slate-200`, `text-slate-400`, `text-slate-500`).
   - Use clean monospace styling for technical data (hashes, paths, status codes, commands).

3. **Color & Theme**:
   - Use consistent CSS variables and tailored color palettes.
   - Anchor background colors (`#0d1117`, `#161b22`, `#21262d`) with purposeful accent colors (emerald for success/health, amber for warnings/steering, cyan/purple for agents and active pipelines).

4. **Spatial Balance & Polish**:
   - Use intentional padding and spacing scales. Avoid cramming elements together or leaving awkward dead space.
   - Provide visual feedback for all interactive states (hover transitions, active clicks, focus outlines).
